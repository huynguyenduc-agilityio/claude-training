# EXP-104: Export a month of usage records to CSV

- **Type:** Feature
- **Priority:** Low
- **Reporter:** Finance team

## Description

As a finance analyst, I want to download the usage records of a month as a CSV file, so that I
can attach them to the monthly cost report and check them in a spreadsheet.

## Acceptance criteria

- **Given** a month is selected on the dashboard
  **When** I click "Export CSV"
  **Then** a file named `usage-YYYY-MM.csv` is downloaded.
- The file has one row per usage record shown in the table, with a header row.
- Columns: time, project, model, input tokens, cached input tokens, output tokens, cost.
- The sum of the cost column equals the total shown under the table.
- If the month has no records, the button is disabled.
