# EXP-111: Add a usage record from the dashboard

- **Type:** Feature
- **Priority:** Low
- **Reporter:** Training Day 11, role-day exercise

## Description

Usage records can only be added by calling `POST /api/usage` directly. The dashboard has a month
input and an Export CSV button, and no form. A person who wants to record usage by hand has to write
the request themselves.

Add a form to the dashboard that sends a record to the existing API.

## Acceptance criteria

- The dashboard shows a form with: time, model, project, input tokens, cached input tokens (optional)
  and output tokens.
- The time starts at the current local time. The model is chosen from `GET /api/models`.
- Submitting a valid record sends `POST /api/usage`. On `201`:
  - the form shows a success message that names the month of the record
  - the totals, breakdowns and records table reload for the month on screen
  - the token fields are cleared; time, model and project stay
- When the API rejects the record, the form shows the API's `error` text and keeps what was typed.
  Nothing else on the page changes.
- An empty token field is not sent as `0`. An empty cached field is sent as no value. An empty input
  or output field is rejected by the API with its own message.
- The API stays the only place that decides what is valid. The form has no rules of its own.
- A request that fails without a response from the API shows an error and keeps what was typed.
- The API, its validation and the existing tests do not change. No new dependency.
