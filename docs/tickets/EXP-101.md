# EXP-101: Dashboard total doesn't match the usage records

- **Type:** Bug
- **Priority:** High
- **Reporter:** Finance team
- **Status:** In progress

## Description

When I open the dashboard and compare the "Total cost" card with the total at the bottom of the
"Usage records" table, they are different. The difference is small, a few cents to a few tens of
cents, but we copy these numbers into the monthly cost report and they must match exactly.

The request count also looks slightly off sometimes.

## Acceptance criteria

- For any selected month, the "Total cost" card equals the total shown under the usage records
  table.
- The "Requests" card equals the number of rows in the usage records table.
- The budget percentage is based on the same total.

## Repro (filled in by the developer)

**Environment**

- Commit `f0fee2a`, fresh clone, `pnpm install` then `pnpm dev`.
- Default config: no `.env` (`APP_TIMEZONE=Asia/Ho_Chi_Minh`, `MONTHLY_BUDGET_USD=30`).
- Data: sample data from `pnpm seed` (890 records, 2026-08-01 to 2026-10-19).
- Node 22, Windows 10, Chrome-based browser.

**Steps**

1. Clone the repo, run `pnpm install`, `pnpm seed`, then `pnpm dev`.
2. Open http://localhost:5173 and pick month **2026-09**.
3. Compare the "Total cost" and "Requests" cards with the "Usage records" heading and the
   "Total" row under the table.

**Expected**

The cards equal the table: same total cost and same number of requests.

**Actual**

| Month | Card total | Table total | Card requests | Table rows |
|---|---|---|---|---|
| 2026-08 | $37.15 | $36.86 | 323 | 320 |
| 2026-09 | $24.58 | $24.84 | 346 | 347 |
| 2026-10 | $14.86 | $14.90 | 221 | 223 |

Every month differs, in both directions. The same numbers come back from the API:
`GET /api/summary?month=2026-09` returns `totalCost: 24.58, recordCount: 346`;
`GET /api/usage?month=2026-09` returns `totalCost: 24.84` with 347 items.

**Evidence:** [dashboard screenshot](../lessons/day-02-ticket-analysis/evidence/exp-101-dashboard-2026-09.jpg),
[API totals per month](../lessons/day-02-ticket-analysis/evidence/exp-101-api-totals.jsonl).

**Note:** on a fresh clone the dashboard is empty until `pnpm seed` is run; `app/README.md` does
not mention this step.
