# EXP-102: Alert when monthly spending passes 80% of the budget

- **Type:** Feature
- **Priority:** Medium
- **Reporter:** Engineering manager
- **Status:** Done
- **Fixed in:** [MR !7](https://gitlab.asoft-python.com/huy.nguyenduc/claude-training/-/merge_requests/7) (merge commit `26c76dd`)

## Description

As an engineering manager, I want to be warned when our AI spending gets close to the monthly
budget, so that I can slow down usage before we go over.

## Acceptance criteria

- When spending for the current month reaches 80% of the budget, the dashboard shows a warning
  banner at the top.
- When spending reaches 100%, the banner turns red and says the budget is exceeded.
- The banner states the amount spent, the budget and the percentage.
- The team is notified when the 80% threshold is crossed.
