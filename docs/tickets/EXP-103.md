# EXP-103: lyra-flash costs higher than the provider invoice

- **Type:** Bug
- **Priority:** Medium
- **Reporter:** Platform team

## Description

Our provider invoice for lyra-flash is lower than what the tracker shows. The provider lowered
the lyra-flash price recently: input is now $0.20 per million tokens and output $2.00 per million
tokens. The tracker still uses the old price.

## Acceptance criteria

- Usage of lyra-flash is priced with the new input and output prices from the date of the price
  change.
- Usage before the price change keeps the old price.
- Other models are not affected.
