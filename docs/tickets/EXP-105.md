# EXP-105: API accepts negative token counts

- **Type:** Bug
- **Priority:** Medium
- **Reporter:** QA
- **Status:** Done
- **Fixed in:** [MR !3](https://gitlab.asoft-python.com/huy.nguyenduc/claude-training/-/merge_requests/3) (merge commit `613ee2d`)

## Description

`POST /api/usage` accepts a record with a negative token count. The record is saved and lowers
the month total.

Steps:

1. Send:
   ```json
   {
     "timestamp": "2026-10-10T08:00:00Z",
     "model": "orion-mini",
     "project": "support-bot",
     "inputTokens": -50000,
     "outputTokens": 200
   }
   ```
2. The API answers `201 Created` and the record appears in the dashboard with a negative cost.

## Acceptance criteria

- `inputTokens`, `outputTokens` and `cachedInputTokens` below zero are rejected with
  `400` and a message naming the field.
- Valid records are still accepted.
